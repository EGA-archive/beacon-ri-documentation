Documentation Beacon Template UI Versioning
Beacon Template UI
Versioning
Version 2.0.0 (Planned for 1 November 2026)
This major release introduces a more flexible runtime configuration system with built-in validation, allowing deployers to customize query options, filters, genomic examples, and download settings without rebuilding the UI. Genomic search and query building have also been improved with clearer suggestions, better input validation, and enhanced support for genomic annotations and amino acid changes.

The results experience has been expanded with dedicated detailed records pages, improved table navigation, keyword highlighting, configurable data downloads, and clearer data visibility information. The release also includes improvements to authentication, responsive layouts, accessibility of UI controls, and deployment, including a new container health check endpoint.

Version 1.1.0 (26 March 2026): Beacon Template UI Version 1.1.0
This release introduces support for authenticated API requests using bearer tokens and ARM64 Docker images. It also includes improvements to genomic query handling, responsive layouts, and configuration options.

Version 1.0.0 (4 February 2026): Beacon Template UI Version 1.0.0
The first official release of the Beacon Template UI, providing a configurable interface for single Beacons and Beacon Networks, including genomic queries, filtering terms, and results visualization.

Upcoming Iterations
Future releases of the Beacon Template UI will continue to introduce new features and improvements based on feedback from users and deployers. Additional functionality will be announced as it becomes available.

The documentation is continuously updated to reflect new features and improvements.
